# Contributing to Skill-Bridge

Thanks for contributing to Skill-Bridge.

## Development workflow

1. Fork or clone the repository.
2. Create a focused branch from `main`.
3. Install the frontend and backend dependencies.
4. Make a small, focused change.
5. Test the affected part of the application locally.
6. Open a pull request with a clear description of the change.

## Project structure

- `frontend/` — React/Vite client application
- `backend/` — Python API and service layer
- `backend/routes/` — API route modules
- `backend/services/` — application and matching services

## Pull requests

Please include:

- What changed
- Why the change was needed
- How it was tested
- Any known limitations or follow-up work

Keep unrelated changes out of the same pull request whenever possible.

## Commit messages

Use concise messages that describe the change, for example:

- `fix: handle empty resume uploads`
- `feat: add opportunity matching filter`
- `docs: improve setup instructions`

## Reporting bugs

When reporting a bug, include the steps to reproduce it, the expected behavior, the actual behavior, and relevant error messages or screenshots.

Thank you for helping improve Skill-Bridge.
